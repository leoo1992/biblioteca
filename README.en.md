# Book and Author Management

A responsive application for managing books and authors with CRUD operations. Books are associated with authors, and records are persisted in browser storage.

## Features
- Create, list, view, and delete books
- Create, list, view, and delete authors
- Associate each book with an author
- Responsive interface for desktop and mobile

## Stack
- React 19 and TypeScript
- Vite
- Radix UI Themes
- TanStack Table
- React Hook Form
- Context API and Local Storage

## Run

```bash
npm install
npm run dev
```

Build with `npm run build`; run lint with `npm run lint`.
